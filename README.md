# Living in SAMSUNG: 삼성 리빙가전 사용설명 QA 챗봇

"Living in SAMSUNG"은 삼성 리빙가전 제품 사용자를 위한 맞춤형 QA 챗봇 서비스입니다. 이 챗봇은 사용자가 제품 사용 중 직면하는 문제에 대해 즉각적이고 정확한 답변을 제공하여 사용자 경험을 향상시키는 것을 목표로 합니다.

---

## 주요 기능

- **즉시 질의응답(Q&A):** 사용자의 질문에 대해 제품 매뉴얼 데이터를 기반으로 신속하고 정확한 답변을 제공합니다.
- **사용자 맞춤 정보 제공:** 초보자와 숙련자 모두에게 적합한 수준의 가이드를 제공합니다.
- **직관적인 UI/UX:** 간단한 대화형 인터페이스를 통해 사용자가 복잡한 매뉴얼을 탐색하지 않고도 필요한 정보를 쉽게 확인할 수 있습니다.

---

## 사용 방법

1. 챗봇 서비스에 접속합니다.
2. 사용 중인 삼성 리빙가전 제품과 관련된 질문을 입력합니다.
3. 챗봇이 제품 매뉴얼 데이터를 기반으로 질문에 대한 답변을 제공합니다.
4. 필요한 경우 추가 질문을 입력하여 더 자세한 정보를 얻을 수 있습니다.

---

## 목표 및 기대 효과

- **목표:**
  - 삼성 리빙가전 사용자를 대상으로 제품 매뉴얼 기반의 자동화된 질의응답 서비스를 제공하여 사용자 경험을 향상시킵니다.
  - 매뉴얼 검색 과정의 불편함을 최소화하여 고객 만족도를 높입니다.
  - 고객 서비스 팀의 업무량을 줄여 효율성을 개선합니다.

- **기대 효과:**
  - 사용자는 문제 해결 시간을 단축할 수 있습니다.
  - 삼성 브랜드의 이미지와 고객 충성도가 강화됩니다.

---

## 데이터 구성 및 처리 방법

1. **원천 데이터:** 삼성전자 공식 웹사이트에서 제공하는 제품 매뉴얼 PDF 파일.
2. **데이터 수집:**
   - 웹사이트에서 매뉴얼 파일을 다운로드하거나 웹 크롤링 기술을 활용하여 일괄 수집.
3. **데이터 처리:**
   - OCR 기술을 사용하여 PDF 문서를 텍스트 데이터로 변환.
   - 텍스트 데이터 전처리 및 구조화.
   - 데이터 품질 점검 및 정제.
   - LLM(대형 언어 모델)을 활용한 RAG(Retrieval-Augmented Generation) 파이프라인 구축.
